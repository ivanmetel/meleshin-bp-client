# ЛК клиента — коммерческое предложение и смета

Клиентская половина демо машины сборки КП (ТЗ BP auto-assembly, 30.09.2026): личный кабинет, который открывается клиенту на этапе согласования КП. Клиент видит опубликованное КП — смету и документ, сохраняет PDF.

**Смотреть: <https://ivanmetel.github.io/meleshin-bp-client/>**
**Админка (конструктор): <https://ivanmetel.github.io/meleshin-bp-admin/>**

Все данные демо вымышлены: объект 2699-Limassol-Apartment, суммы, участники и контакты не существуют.

## Источник состояния — админка

Движок и данные клиент не дублирует: страница грузит их со страницы админки (meleshin-bp-admin). Состояние приходит двумя путями:

- **опубликованное** — `published.json` репо админки (манифест + вариант + статус): правки в админке и push меняют ЛК;
- **предпросмотр** — ссылка «Предпросмотр ЛК клиента ↗» из админки передаёт текущее состояние конструктора в адресе (`#preview=…`): правки видны клиенту сразу, до публикации.

## Клиентская смета

Структура клиентского бюджета: **экраны «Условия / Работы / Материалы» — в правой колонке героя, под «Стоимость по проекту» («Условия» — сам документ КП, исключающий вид; «Работы» и «Материалы» — переключатели, нажаты по одной или обе, кнопки «Все» нет); слева — только фильтр помещений: заголовок «Помещение» и вертикальный список Все · Кухня · Санузел · Зал · Спальня 1 · Спальня 2 (клик по помещению в «Условиях» возвращает к таблицам)**. Встроенный калькулятор: **каунтер = число строк таблицы, итог блока = Σ стоимости показанных строк, «Стоимость по проекту» = сумма итогов блоков** (21 688 + 12 400 = 34 088 €) — клиент может проверить каждое число по видимой таблице; счётчики видны только при одном экране, при обоих считать нечего.

- одинаковые имя+цена — **одна строка с суммарным объёмом** (работы «Все» — 13 позиций, материалы — 11; правило то же, что в документе КП); сопутствующие ед. мес. — последние строки таблицы работ, в каунтеры не входят; выбранное помещение — свои строки (работы 7/5/8/8+9, материалы 6/6/8/8/8);
- **единая решётка**: строки навигации и строки таблиц лежат на общих горизонталях — рейл зеркалит панель полоса в полосу («Помещение» 44 ↔ название блока, отступ 36 ↔ шапка таблицы, комнаты 40 ↔ строки таблицы); при обоих экранах вторая таблица возвращается на ту же решётку (40 + 44 + 36 = 120 = 3 × 40);
- две таблицы (канон): «Строительно-монтажные, отделочные и сопутствующие работы» и «Материалы» (черновые, в стоимости); отделочных материалов клиента в смете нет — они «в стоимость не входят»;
- таблица: # · Работа/Материал · Ед. · Кол&#8209;во · Цена за ед., € · Стоимость, € — без столбца «Помещение»; заголовки в одну строку; ширины: имя гибкая, числовые по заголовку, Ед. — «компл.», Кол-во — «9 999,99»; числа не переносятся; € — только в заголовках и итогах шапки;
- тёмная панель (градиент #2B2826→#3D3734, виньетка) — утверждённое UI-решение; геометрия навигации постоянна — выбор меняет строки, суммы и активные цвета;
- «Условия» — экран той же панели сметы (рамка не меняется между Условия/Работы/Материалы): в полосе названия — «Коммерческое предложение» (заголовок в карточке не повторяется), документ открывает полоса заголовка корпуса BP — лого слева (23 px, в печати 6 мм) + бренд, линия снизу (в печати и на листах полоса ещё и называет документ: «MELESHIN LTD | Коммерческое предложение»); «Фото объекта» — заголовок один, на первой полосе, продолжение без него; внутри — весь документ КП читаемой веб-карточкой (без экранных листов А4 и без слова «предпросмотр»), таблица работ одна, ширины столбцов — по ролям через colgroup (№ 4,5% / Ед. 9% / Кол-во 11% / Цена 16,5% / Стоимость 17%, имя гибкая), шапка таблицы на светлом фоне — ink-2 (контраст ~7:1), итог таблицы — 14 px жирный (промежуточная сумма), единственное число 20 px — строка конечной цены «Стоимость по проекту … + 19% VAT»; подпись менеджера замыкает документ, за ней контактная строка корпуса (бренд | +357 77 788811 | order@meleshin.com.cy | Instagram: renovation_cyprus), под ней кнопка «Сохранить PDF» (прозрачный фон, светлая рамка, белый текст — читаема на тёмной панели). В печать уходит только документ (кабинет не печатается): состав страниц задан нормой, не потоком — А4, поля 13/14/13 (контент 182 × 271 мм), 4 страницы: 1 «Объект» (полоса + титул/описание + план + фото ≈259 мм), 2 «Состав работ» (одна таблица + итог, организация ≈228), 3 «Границы» (не входят, согласования, взаимодействие ≈225), 4 «Условия и финал» (оплата, галерея, подпись + контактная строка ≈169); строк таблицы больше 18 → 5 страниц со сдвигом зон; шапку таблицы на каждой её странице повторяет браузер, ряды изображений в печати — inline-block (печатный движок Chrome валит flex-ряды в столбец);
- шрифт демо один на обеих страницах — Inter (веса 400–800; акценты — весом, числа — табличными цифрами), кегли 12/14/16/20/28.

Кабинет показывается на русском; язык кабинета — тумблер в админ-манифесте (ru активен, en — решение 2 ТЗ `[ ]`). Фирменный шрифт Involve в веб-демо заменён на Inter.

## Файлы

| Файл | Назначение |
|:--|:--|
| `index.html` | каркас кабинета (топбар, герой, смета, печатный документ) |
| `client.css` | стили кабинета: общая база + клиентская оболочка и печать |
| `client.js` | загрузка состояния (опубликованное / предпросмотр) и события кабинета |

Движок (`engine.js`), данные (`data.js`) и опубликованное состояние (`published.json`) клиент грузит со страницы админки — код не дублирован.

## Запуск

Опубликовано — открывать в браузере. Локально: любой локальный сервер в папке; чтобы ЛК взял движок и данные локальной админки — `?admin=http://localhost:8080/`.
