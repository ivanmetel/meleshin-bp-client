# ЛК клиента — коммерческое предложение

Клиентская половина демо машины сборки КП (ТЗ BP auto-assembly, 30.09.2026; ЛК v2 — 02.10.2026): личный кабинет, который открывается клиенту на этапе согласования КП. Клиент видит опубликованное КП — документ и состав работ по помещениям, сохраняет PDF.

**Смотреть: <https://ivanmetel.github.io/meleshin-bp-client/>**
**Админка (конструктор): <https://ivanmetel.github.io/meleshin-bp-admin/>**

Все данные демо вымышлены: объект 2699-Limassol-Apartment, суммы, участники и контакты не существуют.

## Источник состояния — админка

Движок и данные клиент не дублирует: страница грузит их со страницы админки (meleshin-bp-admin). Состояние приходит двумя путями:

- **опубликованное** — `published.json` репо админки (манифест + вариант + статус): правки в админке и push меняют ЛК;
- **предпросмотр** — ссылка «Предпросмотр ЛК клиента ↗» из админки передаёт текущее состояние конструктора в адресе (`#preview=…`): правки видны клиенту сразу, до публикации.

## Вкладка КП (v2, 02.10)

Одна вкладка — само КП (решения Ивана 02.10: нет материалов, одна вкладка с составом работ по помещениям, печать для всех). Вкладка «Смета» и экраны «Условия / Работы / Материалы» умерли: правая колонка героя заканчивается ценой, кабинет открывается сразу в документ.

- **рейл «Помещение»** (Все · Кухня · Санузел · Зал · Спальня 1 · Спальня 2) фильтрует таблицу работ **внутри документа** — клик по помещению не уводит из КП: «Все» — таблица документа (13 позиций после схлопывания одинаковых имя+цена + сопутствующие ед. мес. последними строками, сквозная нумерация 1–15, «Итого» 21 688,00); помещение — тот же вид таблицы с составом этого помещения: нумерация с 1, замыкающая плашка суммирует видимые строки (Кухня — 7 строк, «Итого» 2 444,00), сопутствующие без помещения показываются только в «Все»; остальной документ (описание, границы, оплата, финал) выбор не меняет;
- счётчики рейла — строки работ после схлопывания: 13 / 7 / 5 / 8 / 8 / 9 (счётчики материалов умерли вместе с экраном);
- **материалы — в цене, не на экране**: черновые материалы 12 400 € остаются в «Стоимости по проекту» (34 088 = 21 688 + 12 400; строка расшифровки в «Условиях оплаты» и тексты документа их называют), таблицы материалов в кабинете нет; отделочные материалы клиента — «в стоимость не входят»;
- **решётка рейла** 44 / 36 / 40 (шапка / отступ / строки) — привязка к карточке документа замером: шапка «Помещение» лежит на полосе названия блока панели;
- тёмная панель (градиент #2B2826→#3D3734, виньетка) с полосой названия «Коммерческое предложение» — утверждённое UI-решение; внутри — весь документ КП читаемой веб-карточкой: документ открывает полоса заголовка корпуса BP (лого слева 23 px + бренд, линия снизу; в печати и на листах полоса ещё и называет документ: «MELESHIN LTD | Коммерческое предложение»), «Фото объекта» — заголовок один, на первой полосе; таблица работ одна — настоящий `<table>` с colgroup по ролям (№ 4,5% / Ед. 9% / Кол-во 11% / Цена 16,5% / Стоимость 17%, имя гибкая), шапка на светлом фоне — ink-2 (контраст ~7:1), итог таблицы — 14 px жирный, единственное число 20 px — строка конечной цены; подпись менеджера замыкает документ, за ней контактная строка корпуса (бренд | +357 77 788811 | order@meleshin.com.cy | Instagram: renovation_cyprus), под ней «Сохранить PDF» (прозрачный фон, светлая рамка, белый текст);
- **печать — полный документ для всех помещений**: фильтр помещений — экранный вид, печатная сборка идёт от манифеста и в PDF не попадает (при выбранной «Кухне» PDF несёт все 15 строк и «Итого» 21 688,00); в печать уходит только документ: А4, поля 13/14/13 (контент 182 × 271 мм), 4 страницы по норме — 1 «Объект» ≈259 мм, 2 «Состав работ» ≈228, 3 «Границы» ≈225, 4 «Условия и финал» ≈169; строк таблицы больше 18 → 5 страниц со сдвигом зон; шапку на каждой странице таблицы повторяет браузер, ряды изображений в печати — inline-block (печатный движок Chrome валит flex-ряды в столбец);
- шрифт демо один на обеих страницах — Inter (веса 400–800; акценты — весом, числа — табличными цифрами), кегли 12/14/16/20/28.

Кабинет показывается на русском; язык кабинета — тумблер в админ-манифесте (ru активен, en — решение 2 ТЗ `[ ]`). Фирменный шрифт Involve в веб-демо заменён на Inter.

## Файлы

| Файл | Назначение |
|:--|:--|
| `index.html` | каркас кабинета (топбар, герой, смета, печатный документ) |
| `client.css` | стили кабинета: общая база + клиентская оболочка и печать |
| `client.js` | загрузка состояния (опубликованное / предпросмотр) и события кабинета |

Движок (`engine.js`), данные (`data.js`) и опубликованное состояние (`published.json`) клиент грузит со страницы админки — код не дублирован.

## Запуск

Опубликовано — открывать в браузере. Локально: любой локальный сервер в папке; чтобы ЛК взял движок и данные локальной админки — `?admin=http://localhost:8080/`.

## Ограничения

- Сохранение PDF — печать браузера (А4, только документ, 4 страницы по норме); в производстве — marp-cli `[ ]`.
- en-профиль `[ ]`; мобильная компоновка вкладки КП `[ ]` (ТЗ ЛК v2 §7); судьба MATERIALS_ROWS в демо админки `[ ]` (ТЗ ЛК v2 §4 — в кабинете они больше не показываются).
- Демо-объект единственный.
